## 四、CN2 GIA和CN2 GT到底差在哪

买香港Linux云服务器绕不开CN2这个概念。简单说，CN2是中国电信的下一代承载网，相比传统163骨干网，拥堵更少、速度更快、丢包率更低。恒创的CN2线路分两种：

**CN2 GIA**：最高级别，全程走电信高速通道，速度最快，价格也稍贵。电信用户访问全程走59.43开头的CN2节点，晚高峰表现稳定。

**CN2 GT**：混合线路，国际段走CN2，国内段可能切换到163网络，价格更便宜，但高峰期偶尔会有拥堵。

恒创香港云服务器默认走CN2 GIA线路，10Gb中国频宽直连电信、联通、移动三网。如果你主要面向国内用户，CN2 GIA是首选；如果业务面向国际，BGP优化线路或国际线路会更合适。香港二区提供BGP精品、优化、国际、高防四种线路可选，香港一区仅提供BGP精品线路。
